# Профиль игрока Gazyava Tap

В игровом экране добавлена карточка профиля:

- имя из Telegram WebApp (имя или username);
- текущий титул и уровень из серверного `get_player_progression`;
- актуальный баланс игровых очков;
- XP, количество открытых трофеев и эксклюзивных скинов;
- до четырёх открытых редких, эпических и легендарных трофеев;
- ручное обновление данных профиля;
- отправка краткой карточки прогресса через Telegram share URL с deep link на Mini App.

Очки и XP отображаются из игровых/серверных источников. Количество трофеев и скинов загружается через защищённые действия Edge Function `game`. Профиль не меняет игровые балансы и не выдаёт наград.

Проверка интерфейса: обновление очков привязано к `applyServerData`, а уровень/XP загружаются через `player_progression`. Telegram-публикация использует стандартный `t.me/share/url`; фактическая отправка зависит от клиента Telegram и требует ручной проверки в Mini App.
